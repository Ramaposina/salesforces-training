# Salesforce Platform Basics

## **1. What is Salesforce Platform?**

Salesforce Platform is a cloud-based platform used to develop business applications and manage customer relationships.

## **2. Explain**

### **App**
An App is a collection of tabs and features for a specific business purpose.

### **Object**
An Object is a database table used to store data.

### **Tab**
A Tab helps users access objects and features easily.

## **3. Difference: Configuration vs Coding**

| Configuration | Coding |
|---------------|--------|
| Uses built-in tools | Uses programming |
| Easy to implement | Requires coding skills |
