**1. What is Flow Builder?**

Flow Builder is a declarative automation tool in Salesforce used to automate business processes without writing much code. It allows admins and developers to create workflows using a drag-and-drop interface.
Using Flow Builder, organizations can:
  1.Automate repetitive tasks
  2.Update records automatically
  3.Send notifications or emails
  4.Guide users through screens
  5.Integrate different business processes
 Flow Builder helps improve productivity, reduce manual work, and maintain data accuracy in enterprise systems.


**2. Types of Flows**

**Screen Flow**

   A Screen Flow is an interactive flow that displays screens to users and collects input from them.
   Features
    1.User interaction through forms and screens
    2.Buttons, text fields, dropdowns, and checkboxes
   3.Can create, update, or delete records
   
  **Example**
  
     An employee leave request form where users:
      1.Enter leave details
      2.Submit the request
      3.Manager receives approval notification
      
  **Use Cases**
  
     1.Registration forms
     2.Feedback forms
     3.Guided troubleshooting
     4.Multi-step data entry
     
**Record-Triggered Flow**

   A Record-Triggered Flow runs automatically when a record is:
    1.Created
    2.Updated
    3.Deleted
  It works in the background without user interaction.
  
**Features**

   1.Fully automated
   2.Runs instantly after record changes
   3.Replaces many workflow rules and process builders
   
**Example**

   When a new Contact is created:
   1.Send welcome email
   2.Assign follow-up task
   3.Update related Account status
   
**Use Cases**

   1.Automatic notifications
   2.Record updates
   3.Approval automation
   4.Data validation

**5. Manual vs Automated Process**

| Manual Process | Automated Process |
|-----------------|------------------|
| Requires human effort | Runs automatically |
| Time-consuming | Faster execution |
| Higher chance of errors | More accurate |
| Difficult to track | Easy monitoring |
| Repetitive tasks | Efficient workflow |
| Delayed responses | Instant actions |

**6.Reflection: Why Automation Matters in Enterprise Systems**

     Automation is important in enterprise systems because it improves efficiency, productivity, and accuracy. Large organizations handle thousands of records and business operations daily. Manual processing can lead to delays and errors.
     With automation:
      1.Tasks are completed faster
      2.Employees focus on important work
      3.Business processes become standardized
In Salesforce, Flow Builder helps companies automate operations without extensive coding knowledge. This makes digital transformation easier and reduces development time.
Automation also supports scalability. As businesses grow, automated systems can handle increased workloads efficiently.
